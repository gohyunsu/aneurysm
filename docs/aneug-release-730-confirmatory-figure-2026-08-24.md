# Release-730 confirmatory figure protocol

The historical prediction-blind figure utility is fixed to the obsolete
51-case v4 outer split. It remains preserved. The active paper instead binds a
separate non-executable protocol to the exact 73-case locked test and its
release-730 split evidence.

After models, checkpoints, endpoints and the private T0 activation are frozen,
the selector reads all 73 reference cycles and no predictions. It ranks cases
by area-weighted mean reference OSI and selects the 10th, 50th and 90th
percentile ordinals, breaking exact ties by the frozen private test-loader
order. Within each selected case, a trace vertex is chosen at the
area-weighted 90th percentile of valid reference OSI. No case identifier is
emitted.

Reference, strongest control and proposal must then use the same coordinates,
mask and canonical orthographic camera. TAWSS limits come from the full range
of the three selected references; OSI remains fixed to [0, 0.5]. The 80-phase
trace uses the same reference-selected vertex for all methods. Candidate or
control values cannot affect selection or clipping.

This source does not open T0, read a field, render a figure or create a paper
claim. The actual renderer and result hashes must be bound only after frozen C0
checkpoints and a fresh private T0 activation exist. Use only introai9, never
junjinyong, and do not maintain the public site.
