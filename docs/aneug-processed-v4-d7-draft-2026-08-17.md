# Dormant D7 train-field admission draft

D7 is a fresh, non-executable scientific-contract draft. It does not repair,
resume, rerun, reopen or relabel closed D6, and it does not turn E0 engineering
evidence into scientific evidence. No D7 runner or PBS wrapper exists.

If separately selected, a fresh executable version would bind the immutable
method-free D6 kernel and D5 component split, read only 406 D5-train field
tensors plus shared finest faces, and keep all validation, outer-test and
auxiliary tensor values sealed. Its noncompensatory gate remains mesh/stored-
normal agreement, WSS tangency, temporal consistency, valid TAWSS/OSI,
unclipped RRT-denominator support and the Jensen cone. Thresholds and metrics
cannot be changed after selection.

The required execution envelope incorporates E0 rather than repeating D6's
unobserved pre-runner path. A fresh private record directory must exist before
submission; the attempt marker and internal log must precede strict shell mode,
profile initialization and every scientific access. The wrapper may not source
`/etc/profile`, must use the approved absolute Python and exact clean Quality-
passed checkout, and must treat scheduler stdout/stderr as non-evidence because
PBS staging is known to fail independently.

Even after selection, the maximum would be one introai9 CPU 4, 64 GB, GPU 0
attempt. Any outcome closes that selected version. A pass would permit only
registration of bounded train/validation baseline development—not immediate
model training, outer-test access, a result or a paper claim.

This draft is unselected: field reads, submission, model, GPU, validation,
outer test and paper evidence remain zero. It may never be edited in place into
an executable contract; selection requires a fresh version. The public site is
not maintained. Never use junjinyong.
