## 1. Critical adjudication of the proposed analysis

The analysis is correct on the points that control action:

1. field-level accuracy does not logically imply preservation of the
   organization of a tangent vector field;
2. edge 1-forms, Hodge/DEC, equivariance, periodic operators, critical-point
   extraction and tracking are components or direct controls, not standalone
   novelty;
3. task stability and an observed, field-error-matched baseline failure must
   precede model development;
4. the historical 32.0/40 source score is immutable provenance, not model
   evidence; and
5. the incomplete CPU execution authorizes neither repair nor escalation.

Three statements require tightening.

First, “a good architecture and sufficient performance could be competitive at
ISBI” is true only as a conditional description of a future result. It is not
evidence that the target is stable, the baseline failure exists, the asset is
executable or the residual gap is unoccupied. It cannot activate a paper.

Second, exact critical-point coordinates, types and worldlines should not be
the first estimand. Near-degenerate zeros can move, split or disappear under a
small remeshing, tolerance or interpolation change. The first method-free
question is whether a boundary-margin signed degree and its abstention set are
stable. Point, type, track and birth/death metrics become secondary endpoints
only after this gate passes.

Third, the phrase “register a fresh version” is incomplete without a material
source change. A new wrapper, downloader, timeout, parser, cache, seed, model
name or protocol timestamp applied to the same objects is not a new evidence
version. Repeatedly searching or repairing those objects would be a local
repair loop.

The Synthetic-AAA code is useful and executable, but it is a generator and
OpenFOAM workflow. Its README explicitly says generated geometries and CFD
results are not committed, apart from four example cases. A pipeline that can
create future data is not an existing independent confirmatory cohort. Running
it now would create a new synthetic development set, not repair the missing
external evidence for intracranial structure fidelity.

The result is finite: every currently known route is either the exact closed
version, semantically insufficient, gated without the required lineage, a
direct-prior endpoint without executable fields, or a generator without a
committed cohort. There is no fresh E0.

## 3. What remains scientifically worthwhile

The retained question is narrower than the proposed architecture:

> Among transient surface-WSS predictors matched on area-weighted field error,
> do robust structural endpoints still disagree, and can a minimal
> representation or objective change reduce that disagreement without a field
> accuracy penalty?

This is potentially a strong ISBI application contribution because it tests a
failure of the dominant evaluation contract rather than attaching a decorative
module. It is not independently novel yet. Hodge Spectral Duality,
SE(3)-equivariant transient WSS prediction, robust critical-point tracking,
trajectory-preserving compression and aneurysm-specific cardiac-cycle tracking
all constrain what can be claimed.

The phrase “structure-faithful” is therefore an evaluation hypothesis, not a
method name. The proposal cannot claim that oriented edge integration
guarantees zeros, that Hodge decomposition guarantees worldlines, or that a
topology loss is novel. Any future intervention must be selected from an
observed failure mechanism and tested against these controls.

## 4. Whitelisted material re-entry signals

The family may be reconsidered only when a source watch identifies at least
one of the following. A signal requests a fresh source audit; it does not
automatically authorize data access or compute.

1. an official new AneuG/AneuX/Aneurisk version that exposes the actual
   surface-vector schema, physical units, phase/time coordinate, surface-field
   correspondence, boundary convention and immutable independent-family keys;
2. a licensed phase-resolved WSS cohort with a machine-readable case/family
   manifest and enough independent units for a prospectively justified
   development/confirmation split;
3. the AAA or another direct-prior repository releases executable code,
   checkpoints, exact folds and compatible fields sufficient for a faithful
   matched baseline; or
4. a physical or clinical paired reference becomes available with the same
   coordinate system and enough independent anatomies for external
   interpretation.

The following are explicitly not material re-entry signals: README or citation
edits, DOI badges, repository stars, a new wrapper, a timeout increase, parser
changes, local cache recovery, a generated synthetic cohort without a sealed
external field source, accepting terms without schema/lineage, or a new model
name.

## 5. Prospective evidence ladder after a real signal

Only a whitelisted signal can open a new source version. That version must then
proceed in this order.

### E0 · source admission

Freeze source revision, license/terms, checksum manifest, units, time/phase,
surface orientation and family identifiers. Re-run the non-compensatory source
screen. A pass opens one method-free P0 only.

### E1 · method-free stability

Without a learned model, freeze tangent reconstruction, boundary margin,
non-degeneracy threshold, zero tolerance, temporal matching, remeshing levels
and bounded field perturbations. Primary endpoints are signed-degree validity,
stability and abstention efficiency. If these are unstable or vacuous, close
the family.

### E2 · baseline feasibility and failure mechanism

Run Cartesian output, post-hoc tangent projection, equivariant mesh, GHD/RHSIA
and Hodge/HSD controls under the same split and budget. Compare structure only
after matching or stratifying field error. If field error already determines
the stable structure endpoints, or no reproducible separation remains, close
the family without inventing a model.

### E3 · bounded development

Use family-disjoint train/validation partitions, fixed parameter and compute
budgets, validation-only selection and a sealed outer test. The smallest
eligible intervention is an oriented edge-integral output with explicit
tangent reconstruction on a strong shared backbone. Hodge, equivariance and
tracking remain controls. A structural loss is considered only if E2 isolates
a failure that the loss directly addresses.

### E4 · fresh confirmation

Require area-weighted field-error non-inferiority and consistent family-level
improvement in the stable structural endpoints. Critical-point precision/
recall, signed-index discrepancy, trajectory distance and temporally tolerant
birth/death F1 are reported only if E1 made them reliable. Bootstrap and
confidence intervals use patient or generator family, never vertices,
triangles, phases or critical points.

### E5 · interpretation

Show reference, strongest baseline and proposal on the same geometry, phase,
camera and color range with identical symbols and tolerances. The figure may
interpret flow organization; it must not infer rupture risk, treatment utility
or clinical causality without a joined outcome source.
