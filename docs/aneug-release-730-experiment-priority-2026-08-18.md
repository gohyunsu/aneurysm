# Release-730 experiment priority

The paper needs one coherent comparison chain, not every previously discussed
idea. The active sequence is therefore evidence-driven and serial on the sole
authorized introai9 GPU.

## Active sequence

1. Finish the released-class Graph U-Net on 584 train and 73 validation cases.
   This is the indispensable direct prior; job `117056.ECE-util1` must not be
   stopped or duplicated while healthy.
2. Run the GHD-conditioned GINE-GPS U-Net matched comparator. This establishes
   whether geometry descriptors plus local/global mesh processing materially
   strengthen the backbone under the same raw-field protocol.
3. Run the train-response oracle. It can reject an inadequate global manifold
   cheaply, but cannot be reported as learned performance or select a final
   model by itself.
4. Adapt Transolver only after the first two learned baselines are terminal.
   It must use the same information, complete-cycle target, validation metric
   and a disclosed compute envelope.
5. If the oracle is useful, compare response-only, local-only, and
   response-plus-local-residual with one common backbone and budget.
6. Only after a field-competitive combined model exists, compare field-only,
   scalar-functional, OSI, complete-functional and field-anchored objectives.
7. Freeze the candidate, seeds, checkpoint rule, endpoints, paired analysis
   and prediction-blind figure cases before opening the 73-case test once.

## Historical or stopped

The v4 406/51 D9--D12 sequence is preserved as engineering history but does
not enter the release-730 main table, initialize a new model or set a pass
threshold. The obsolete v4 D12 job has already been terminated. Hard post-hoc
tangent projection and moment projection are negative or confounded historical
evidence, not active method components. No other obsolete AURORA GPU job is
active.

## Deferred unless core evidence justifies it

- The 79 processed-only cases are not part of the official main cohort. They
  may later support a training-only augmentation sensitivity analysis without
  changing validation or test.
- LinearNO, Transolver++ and further operator families are deferred. A weakly
  adapted long baseline list is less informative than three strong matched
  controls.
- Critical-point/worldline losses, Hodge decomposition, hard periodic closure,
  hard tangent projection, separate TAWSS/OSI heads and clinical rupture claims
  are outside the active paper identity.
- Multi-seed confirmation begins only after validation has narrowed the model
  family. The locked test is not used for that narrowing.

## Decision logic

A poor released Graph U-Net does not validate the proposal; it raises the
importance of the GHD-GPS and Transolver controls. A weak response oracle
removes the global manifold branch. A strong oracle with weak learned
response-only performance identifies coefficient prediction—not basis rank—as
the bottleneck. Functional alignment is retained only if it improves TAWSS/OSI
without a material paired field-error tax. The paper identity remains
conditional until these comparisons exist.
