01 · FOUNDATION

먼저, 무엇을
예측하려는가?

“동맥류가 있다”와 “그 안에서 피가 어떻게 흐른다”는 서로 다른 질문입니다. AURORA는 두 질문 사이의 연결을 다룹니다.

ANATOMY

뇌동맥류

뇌혈관 벽 일부가 주머니처럼 부풀어 오른 구조입니다. 위치, 목의 폭, 크기, 비대칭성, 주변 가지의 각도는 병변마다 다릅니다. 이 3차원 형태는 CTA나 MRA에서 분할한 표면 mesh로 표현할 수 있습니다.

PHYSIOLOGY

혈류역학

같은 모양에서도 유입 유량, 심장 박동 파형, 출구별 유량 분배, 혈액 점도가 달라지면 속도·압력·벽면 전단응력이 달라집니다. 즉, anatomy는 중요한 원인이지만 혈류를 혼자 결정하지는 않습니다.

CFD IN PLAIN LANGUAGE

CFD는 “가상 풍동”에 가깝습니다.

Computational Fluid Dynamics는 혈관 내부를 아주 작은 계산 요소로 나눈 뒤, 질량과 운동량 보존 방정식을 수치적으로 풉니다. 입구에는 시간에 따른 유량이나 속도, 출구에는 압력 또는 유량 분배, 벽에는 보통 no-slip 조건을 둡니다.

결과는 한 환자당 하나의 숫자가 아니라, 공간과 시간마다 달라지는 속도 벡터와 압력장입니다. 정확한 CFD는 유용하지만 mesh 생성, 경계조건 설정, solver 실행에 많은 시간이 듭니다. neural surrogate는 이 계산을 학습해 빠르게 근사하려는 모델입니다.

CTA/MRA영상 → 3D mesh형태 → CFD / surrogate혈류장 → FunctionalsWSS·OSI → Status analysis연관성
중요한 범위 제한

현재 공개 데이터의 endpoint는 촬영 시점의 ruptured/unruptured 상태입니다. 이 연구는 2년 또는 5년 뒤 파열을 예측하는 전향적 위험 모델이 아니며, 임상 의사결정 도구도 아닙니다.

02 · REPRESENTATION

혈관 표면을
점과 선으로 읽는다.

GNN을 이해하려면 먼저 mesh와 graph를 구분하면 됩니다. mesh는 실제 표면의 기하이고, graph는 신경망이 그 기하를 읽는 계산 구조입니다.

1

Node

표면의 점입니다. 좌표, 법선 방향, 곡률, 목까지의 거리, inlet·wall·outlet 종류를 가집니다.

2

Edge

삼각형에서 이웃한 점 또는 k-nearest neighbor를 연결합니다. 상대 위치와 거리, 법선 각도는 혈관의 국소 모양을 설명합니다.

3

Query

출력을 알고 싶은 위치입니다. 표면 node일 수도 있고 혈관 내부의 임의 좌표일 수도 있습니다.

A TINY EXAMPLE

한 점이 혼자서는 알 수 없는 것

중앙 node곡률 0.34 + 이웃 16개상대 위치·법선 → 국소 주머니neck인지 dome인지

좌표 하나만 보면 그 점이 동맥류 꼭대기인지 부모 혈관의 평평한 부분인지 알기 어렵습니다. 이웃과의 관계를 모으면 곡면의 방향과 구조가 보입니다. 이것이 message passing의 직관입니다.

왜 3D voxel CNN을 바로 쓰지 않나요?

혈관은 가늘고 비어 있는 공간이 많습니다. 균일 voxel grid는 메모리를 많이 쓰고 표면의 미세한 곡률을 흐릴 수 있습니다. mesh/graph는 실제 표면에 계산을 집중합니다. 다만 영상 자체의 질감이 필요하면 CNN encoder를 별도로 결합할 수 있습니다.

03 · LOCAL REASONING

GNN은 이웃의 말을
모아 듣는다.

각 node가 이웃으로부터 메시지를 받고 자기 표현을 갱신하는 과정을 여러 번 반복합니다. AURORA에서는 이 단계가 geometry encoder의 앞부분입니다.

메시지mij = MLP(hi, hj, eij)

나, 이웃, 둘 사이 관계를 작은 신경망에 넣습니다.

→
모으기mi = Σj∈N(i) mij

이웃 순서와 무관하게 메시지를 합칩니다.

→
갱신h′i = U(hi, mi)

새로운 node 표현을 만듭니다.

VERDICT

그래서 “GNN 기반”이라는 말은 반만 맞습니다.

맞는 부분: surface node와 edge, message passing이 geometry encoder의 핵심 국소 연산입니다. 부족한 부분: 모델의 출력은 고정 graph node의 다음 timestep이 아니라, BC를 조건으로 임의 query 위치의 전체 cardiac-cycle field를 내는 operator입니다.

04 · THE HYBRID

Local graph.
Global operator.

전체 구조는 다섯 단계입니다. 각 단계는 하나의 “fancy module”을 더하기 위한 장식이 아니라, 입력에서 최종 검증까지 생기는 구체적인 실패를 막기 위해 존재합니다.

01 · NORMALIZE

해부학적 local frame

neck 중심을 원점으로 두고 부모 혈관 지름으로 크기를 정규화합니다. 스캐너 좌표의 임의 회전·이동을 모델이 외우지 않게 합니다.

입력surface position · normal · curvature · landmarks
02 · ENCODE

Multi-scale GNN stem

4096개 표면 점에서 가까운 곡면 관계를 읽고, 1024·256개 점으로 줄이면서 neck·inlet·outlet·dome의 중요한 점은 보존합니다.

이유hotspot을 잃지 않고 계산량 줄이기
03 · MIX

128 physics tokens

표면 전체를 128개 latent token으로 압축하고 attention으로 멀리 떨어진 inlet, aneurysm sac, outlet의 관계를 연결합니다.

이유long-range flow dependence
04 · CONDITION

Observed / missing BC latent

측정된 파형이 있으면 직접 encode하고, 없으면 해부학적 맥락에 맞는 여러 BC scenario를 샘플링합니다. 이 latent가 decoder의 각 층을 FiLM으로 조절합니다.

출력 수evaluation에서 기본 K=8 scenarios

Dual-domain operator decoder

05 · IDENTIFIABILITY

같은 혈관에도
여러 흐름이 가능하다.

Boundary condition, 즉 경계조건은 계산 영역의 입구와 출구에서 혈액이 어떻게 들어오고 나가는지 정합니다. geometry-only 배포에서는 이 값이 흔히 없습니다.

고정된 geometryG같은 3D 혈관
+
B₁낮은 유입 B₂중앙 파형 B₃높은 peak
→
여러 plausible fieldH₁, H₂, H₃평균 하나가 아님

THE CENTRAL EQUATION

모르는 BC를 적분해 없앤다.

p(H | G) = ∫ p(H | G, B) p(B | A) dB

G는 geometry, B는 boundary condition, H는 hemodynamic field, A는 위치·부모 혈관 지름 같은 anatomy context입니다. 실제 계산에서는 적분을 정확히 풀지 않고 BC scenario를 여러 번 샘플링해 근사합니다.

잘못된 단순화

모든 사람에게 평균 파형

출력은 안정적으로 보이지만 실제 불확실성보다 지나치게 좁습니다. 틀렸는데 확신하는 모델이 될 수 있습니다.

AURORA의 가설

조건부 BC distribution

train fold에서만 얻은 empirical prior를 사용하고, held-out BC coverage와 interval width를 함께 평가합니다.

이 불확실성이 “파열 확률”인가요?

아닙니다. BC scenario 간 차이는 입력 생리정보 부족에서 오는 hemodynamic uncertainty입니다. rupture-status probability의 불확실성과 별도로 측정하며 서로 바꾸어 말하지 않습니다.

06 · ONE-SHOT CYCLE

다음 순간 대신,
주기 전체의 모양을.

일반적인 rollout 모델은 t=0에서 t=1을 예측하고, 그 예측을 다시 입력해 t=2를 만듭니다. 작은 오차가 80번 누적될 수 있습니다.

AUTOREGRESSIVE

t₀→t₁→t₂···t₈₀

한 걸음씩 80번

앞 단계의 오차가 다음 입력이 됩니다. 긴 rollout에서 drift와 위상 오차가 커질 수 있습니다.

AURORA

17개 계수를 한 번에

상수항 1개와 8개 주파수의 sine/cosine 계수 16개로 cardiac cycle을 복원합니다.

h(x,t) = a₀(x) + Σk=1…8[ak(x)cos(2πkt/T) + bk(x)sin(2πkt/T)]
a₀

평균 수준

한 주기 동안의 기본 속도·압력·WSS 수준입니다.

k=1

주된 심장 박동

한 주기에 한 번 반복되는 가장 큰 파형 변화를 담습니다.

k=2…8

세부 파형

peak의 날카로움, 지연, 복잡한 진동을 더합니다.

Fourier가 항상 정답은 아닙니다.

파형이 주기적이라는 가정이 맞는지, 4·8·12 mode 중 어느 수가 충분한지 ablation합니다. 비주기적 과도현상이나 심한 부정맥에는 다른 basis가 필요할 수 있습니다.

07 · DUAL DOMAIN

혈관 안과 벽을
서로 다르게 본다.

WHY RMSE IS NOT ENOUGH

평균 오차가 작아도 중요한 hotspot은 틀릴 수 있습니다.

모델 A낮은 전체 RMSE · hotspot 위치 오류 모델 B조금 높은 RMSE · hotspot/OSI 보존

AURORA는 field error와 함께 hotspot overlap, functional error, real-CFD 기반 status model의 ranking·calibration 보존을 봅니다. 이를 functional sufficiency라고 부릅니다.

GLOSSARY · 16 TERMS

용어가 막힐 때
여기로 돌아오세요.

Boundary condition · BC

계산 영역의 입구와 출구에서 유량·속도·압력 등이 어떻게 주어지는지 정하는 조건.

Calibration

0.7로 예측한 집단에서 실제 양성이 약 70%인지처럼, 확률의 크기가 현실 빈도와 맞는 성질.

CFD

유체의 보존 방정식을 mesh 위에서 수치적으로 풀어 속도·압력장을 얻는 계산.

Cross-sectional status

한 시점에 관측된 ruptured/unruptured 상태. 미래 발생 시간을 예측하는 risk와 다름.

Edge

graph에서 두 node의 관계. mesh의 삼각형 이웃 또는 가까운 점을 연결.

Functional

전체 field에서 계산한 TAWSS, OSI, hotspot 면적 같은 요약 함수.

GNN

node가 edge를 따라 이웃의 정보를 모으고 표현을 갱신하는 신경망.

Latent variable

직접 관측하지 않지만 모델 내부에서 변화 원인을 나타내는 숨은 변수. AURORA에서는 BC scenario를 표현.

Mesh

3차원 표면이나 부피를 점, 선, 삼각형, 사면체 등으로 나눈 계산 표현.

Message passing

이웃 node의 특징과 edge 관계로 메시지를 만들고 합쳐 현재 node를 갱신하는 연산.

Neural operator

고정 크기 벡터가 아니라 입력 함수·geometry에서 출력 함수를 학습하는 모델 계열.

OOD

학습 분포 밖의 geometry, BC, 기관 등 처음 보는 조건.

OSI

한 cardiac cycle 동안 WSS 방향이 얼마나 진동하는지 나타내는 지표.

Query point

학습된 operator에 “이 좌표의 값은?”이라고 묻는 공간 위치.

Surrogate

비싼 CFD solver의 입력–출력 관계를 학습해 빠르게 근사하는 모델.

WSS

흐르는 혈액이 혈관 벽을 접선 방향으로 미는 단위 면적당 힘, wall shear stress.
