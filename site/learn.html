01 · FOUNDATION

먼저, 무엇을
예측하려는가?

“동맥류가 있다”와 “그 안에서 피가 어떻게 흐른다”는 서로 다른 질문입니다. AURORA는 두 질문 사이의 연결을 다룹니다.

ANATOMY

뇌동맥류

뇌혈관 벽 일부가 주머니처럼 부풀어 오른 구조입니다. 위치, 목의 폭, 크기, 비대칭성, 주변 가지의 각도는 병변마다 다릅니다. 이 3차원 형태는 CTA나 MRA에서 분할한 표면 mesh로 표현할 수 있습니다.

PHYSIOLOGY

혈류역학

같은 모양에서도 유입 유량, 심장 박동 파형, 출구별 유량 분배, 혈액 점도가 달라지면 속도·압력·벽면 전단응력이 달라집니다. 즉, anatomy는 중요한 원인이지만 혈류를 혼자 결정하지는 않습니다.

CFD IN PLAIN LANGUAGE

CFD는 “가상 풍동”에 가깝습니다.

Computational Fluid Dynamics는 혈관 내부를 아주 작은 계산 요소로 나눈 뒤, 질량과 운동량 보존 방정식을 수치적으로 풉니다. 입구에는 시간에 따른 유량이나 속도, 출구에는 압력 또는 유량 분배, 벽에는 보통 no-slip 조건을 둡니다.

결과는 한 환자당 하나의 숫자가 아니라, 공간과 시간마다 달라지는 속도 벡터와 압력장입니다. 정확한 CFD는 유용하지만 mesh 생성, 경계조건 설정, solver 실행에 많은 시간이 듭니다. neural surrogate는 이 계산을 학습해 빠르게 근사하려는 모델입니다.

CTA/MRA영상 → 3D mesh형태 → CFD / surrogate혈류장 → FunctionalsWSS·OSI → Status analysis연관성
중요한 범위 제한

현재 공개 데이터의 endpoint는 촬영 시점의 ruptured/unruptured 상태입니다. 이 연구는 2년 또는 5년 뒤 파열을 예측하는 전향적 위험 모델이 아니며, 임상 의사결정 도구도 아닙니다.

02 · REPRESENTATION

혈관 표면을
점과 선으로 읽는다.

GNN을 이해하려면 먼저 mesh와 graph를 구분하면 됩니다. mesh는 실제 표면의 기하이고, graph는 신경망이 그 기하를 읽는 계산 구조입니다.

1

Node

표면의 점입니다. 좌표, 법선 방향, 곡률, 목까지의 거리, inlet·wall·outlet 종류를 가집니다.

2

Edge

삼각형에서 이웃한 점 또는 k-nearest neighbor를 연결합니다. 상대 위치와 거리, 법선 각도는 혈관의 국소 모양을 설명합니다.

3

Query

출력을 알고 싶은 위치입니다. 표면 node일 수도 있고 혈관 내부의 임의 좌표일 수도 있습니다.

A TINY EXAMPLE

한 점이 혼자서는 알 수 없는 것

중앙 node곡률 0.34 + 이웃 16개상대 위치·법선 → 국소 주머니neck인지 dome인지

좌표 하나만 보면 그 점이 동맥류 꼭대기인지 부모 혈관의 평평한 부분인지 알기 어렵습니다. 이웃과의 관계를 모으면 곡면의 방향과 구조가 보입니다. 이것이 message passing의 직관입니다.

왜 3D voxel CNN을 바로 쓰지 않나요?

혈관은 가늘고 비어 있는 공간이 많습니다. 균일 voxel grid는 메모리를 많이 쓰고 표면의 미세한 곡률을 흐릴 수 있습니다. mesh/graph는 실제 표면에 계산을 집중합니다. 다만 영상 자체의 질감이 필요하면 CNN encoder를 별도로 결합할 수 있습니다.

03 · LOCAL REASONING

GNN은 이웃의 말을
모아 듣는다.

각 node가 이웃으로부터 메시지를 받고 자기 표현을 갱신하는 과정을 여러 번 반복합니다. AURORA의 3D target specification에서는 이 단계가 geometry encoder의 앞부분입니다.

메시지mij = MLP(hi, hj, eij)

나, 이웃, 둘 사이 관계를 작은 신경망에 넣습니다.

→
모으기mi = Σj∈N(i) mij

이웃 순서와 무관하게 메시지를 합칩니다.

→
갱신h′i = U(hi, mi)

새로운 node 표현을 만듭니다.

V1 후보형상을 읽는 방식유량 q를 넣는 방식왜 비교하는가
q-PointNet각 점을 독립적으로 encode한 뒤 전체 점의 mean/max를 모음정규화한 q를 각 점과 decoder에 직접 연결edge가 없어도 global pooling만으로 충분한지 확인
kNN-MGN거리로 정한 16개 이웃의 message를 4회 교환q를 node feature에 붙여 처음부터 함께 전달국소 혈관 형상 관계가 실제 이득인지 확인

V1은 8개 유량에서 어떻게 “분포”를 만드나요?

환자 생리 분포를 새로 추정하는 것이 아닙니다. 데이터에 등록된 8개 유량을 같은 확률로 갖는 실험 design law로 두고 모두 열거합니다. 한 seed는 8개 field를 만들고, 세 seed ensemble은 같은 q의 평균을 point prediction으로 사용합니다. Missing-q 평가는 seed 3개와 q 8개의 조합인 24개 field를 사용합니다. 이 ensemble 결과는 backbone selector에 넣지 않으며 구조적 불확실성과 model 불확실성을 분리했다는 주장도 하지 않습니다.

Same-case scaling은 왜 공정한 reconstruction baseline이 아닌가요?

이 control은 validation case의 q=0.0025 실제 velocity field를 이미 본 뒤 다른 q를 power 1.075로 확대합니다. 따라서 같은 geometry에서 반응 곡선이 단순 전역 scaling보다 복잡한지는 물을 수 있지만, geometry와 q만 받아 field를 복원하는 learned model과 같은 입력 조건이 아닙니다. 그래서 response-only oracle로 보고하며 선택과 gate에는 사용하지 않습니다.

VERDICT

이것은 현재 결과가 아니라 3D target specification입니다.

계획된 부분: node와 edge, message passing이 geometry encoder의 국소 연산입니다. 현재 증거: exact/nonlinear gate는 MLP operator로 실행됐습니다. V1 graph 후보는 학습됐지만 relative L2 약 1로 실패했고, 이 절의 전체 graph/token/query stack은 아직 구현·학습되지 않았습니다.

V1e · COMPLETE / FAILED 6 OF 9

Missing inflow를 묻기 전에, 알려진 inflow부터 배울 수 있어야 합니다.

V1의 네 후보는 혈관 내부 4,096개 점과 유량만 보았고 training field조차 충분히 맞히지 못했습니다. V1e는 이를 같은 backbone을 수선하는 문제로 다루지 않습니다. 공식 release에서 확인한 inlet, outlet, wall의 위치·종류·바깥 방향 normal·면적을 source token으로 제공했을 때 fully observed scalar inflow의 velocity field가 먼저 식별 가능한지를 묻습니다.

128 interior + 64 inlet + 64 outlet + 64 wall = 320 source tokens

Boundary variant는 이 320 token을 64 latent token으로 cross-attention한 뒤 4개 self-attention block에서 inlet–sac–outlet의 전역 관계를 섞습니다. Decoder는 각 volume coordinate와 알려진 유량을 query로 받아 3D velocity vector를 출력합니다. Control은 parameter 수와 320-token budget을 그대로 두고 모두 interior point로 채웁니다. 따라서 차이는 “더 큰 모델”이 아니라 physical boundary identity의 정보입니다.

Exact source c62838b의 6 GPU task는 모두 정상 완료됐습니다. Boundary model은 full-q와 response 모두 3/3 seed에서 control보다 좋았고 평균 상대 개선도 10.94%와 6.41%였습니다. 즉 physical boundary identity는 실제 정보를 더했습니다. 그러나 worst-seed train full-q, validation full-q, response L2는 0.77221, 0.87796, 0.94918로 기준 0.25, 0.35, 0.50을 모두 실패했습니다. 상대적으로 덜 나쁜 모델이 충분히 학습된 모델은 아닙니다. 등록대로 current Aneumo 3D line을 local repair 없이 중단하며 Perceiver나 boundary token을 novelty로 주장하지 않습니다.

M0 · EXECUTION-INCOMPLETE / NO VERDICT

좋은 solution sample만으로는 “무엇을 측정할지” 정할 수 없습니다.

측정 후보 Bj의 분포와 solution functional Z의 분포를 각각 정확히 맞혀도, 둘이 함께 움직이는 방식이 틀리면 Bj를 관측한 뒤 Z에 대해 알게 되는 정보가 달라집니다. 상관된 joint와 독립 joint는 marginal이 같아도 post-measurement Bayes risk가 다를 수 있습니다.

Tj(G,B) = [ std(Bj), std(Ψ(F(G,B))) ]

M0는 하나의 joint BC density에서 boundary sample을 뽑고, frozen full-condition operator를 통과시킨 뒤, 여덟 후보마다 이 joint vector를 product kernel로 점수화합니다. 별도 acquisition head나 mask별 density head는 없습니다. Kernel score·probabilistic operator·active acquisition 자체는 선행연구이므로 novelty로 세지 않습니다.

현재 구현 상태

이 페이지는 architecture contract를 설명합니다. Exact·nonlinear PDE의 joint density, conditional operator, strong baselines와 decision evaluation은 구현·실행됐지만 N1c는 실패했습니다. N1c-a는 density objective가 주 병목임을 확인했고 3D GNN은 실행하지 않았습니다. V1e Perceiver baseline은 exact six-task GPU run에서 6/9로 실패했고 current Aneumo 3D line을 중단했습니다. 상대 boundary utility는 method novelty가 아닙니다. M0 joint-pullback은 세 seed 중 두 개만 완료되어 aggregate와 scientific verdict가 없고, local repair 없이 닫혔습니다. Selected method가 아닙니다. “implemented”, “supported”와 “proposed”를 구분합니다.

THE CENTRAL EQUATION

관측하지 못한 BC component만 적분한다.

p(H | G,BM) = ∫ p(H | G,B) q(B¬M | G,BM) dB

G는 geometry, B는 boundary condition, H는 hemodynamic field, M은 관측 component의 mask입니다. Joint Gaussian mixture는 관측 component에 정확히 conditioning할 수 있고, 남은 적분은 BC scenario를 샘플링해 근사합니다.

같은 혈관에서 BC만 바꿔 비교한다.

ΔH = H(G,B₂) − H(G,B₁)

서로 다른 geometry를 비교하면 형상 차이와 BC 차이가 섞입니다. 같은 geometry의 simulation pair는 BC 변화가 만든 field response를 직접 보여 줍니다. 이는 simulator 안의 controlled response이며 환자에 대한 인과 효과는 아닙니다.

ASSET AUDIT · 03 AUG 2026

존재와 학습 가능성을 구분했습니다.

BenchAnXplore 105×80 field는 감사·추출했습니다. Aneumo는 ZIP64 byte-range audit으로 geometry당 8개 steady condition과 내부 NPY contract를 확인했고, 32 base-family × 2 deformation pilot을 등록한 뒤 64 case·512 member selective cache staging과 family-disjoint 40/12/12 case split을 검증했습니다. 다만 train family만 읽는 same-case-anchor physical scaling audit에서 velocity는 21.12% [20.01%, 22.43%]가 남아 통과했지만 pressure는 13.69% [11.90%, 14.96%]로 실패했습니다. Velocity-only eligibility는 당시의 좁은 후보였지만, 이후 N1c와 V1e가 실패해 current Aneumo 3D line은 종료됐습니다. 이를 현재 headline이나 새 method 근거로 되살리지 않습니다. 기존 compact cache에는 boundary patch가 없지만 official ZIP에는 mesh/STL, volume VTU와 inlet/outlet/wall VTP가 있음을 archive 1에서 확인했습니다. 이 사전 발견은 결과가 아닙니다. 이후 V1b가 20 archives·64 cases와 60 train VTP를 metadata/CRC로 감사해 8/8을 통과했습니다. V1c는 geometry decode 전에 20 train case의 세 patch×세 flow, 180 payload에서 q-invariance, topology, area/frame와 기존 cache 좌표계 일치를 검사해 8/8을 통과했습니다. 60/60 patch가 exact q-invariant였고 polygon-valid fraction은 1.0이었습니다. Exact source 369317a의 V1d는 train 40, validation 12, test 0 case의 520 geometry payload를 감사해 9/9을 통과했습니다. 156/156 patch가 q-invariant였고 52/52 case에서 모든 boundary point가 volume point에 exact하게 대응했습니다. 이 asset pass 뒤 V1e known-condition baseline만 학습 전에 고정했습니다. GATE VERDICT · 03 AUG 2026

실패를 architecture 결정으로 연결했습니다.

Frozen D0의 Fourier K=8은 full L2 1.62%, bulge L2 6.16%로 실패했고 K=12도 bulge 2.93%였습니다. Exact G1은 direct masked Gaussian보다 모든 mask에서 나았지만 5개 seed 모두 absolute gate를 통과하지 못했습니다. 따라서 fixed Fourier는 제거했습니다. G1b에서 raw projective error는 iid sampling floor로 설명됐지만 K=2048 missing-mask error 8.53%와 density-only error 7.54%가 남아 G1은 여전히 unsupported입니다. 이를 고치기 위한 G1r은 fresh seed와 validation-only selection, analytic coverage, iid-floor-calibrated projective metric을 실행 전에 고정했습니다. 실제 5-seed 결과에서 coverage, operator, nesting, projective 항은 통과했지만 최악 seed의 density-only mean 7.53%와 end-to-end mean 7.52%가 기준 5%를 넘어 다시 실패했습니다. 다음 단계는 복잡한 3D 학습이 아니라 density representation·optimization·finite-data attribution입니다. 이 DA1 진단도 완료했습니다. 무한히 많은 condition을 안다고 가정한 population-NLL에서는 최악 오차가 0.495%까지 내려가 network가 정답을 표현할 수 있었습니다. 실제 유한 표본으로 학습한 empirical NLL은 4.40–4.86%였습니다. 같은 6,144개 sample에서도 geometry와 반복 condition을 균형 있게 둔 768×8이 기술적으로 가장 안정적이었고, 두 축을 각각 늘려도 오차가 줄었습니다. 따라서 capacity보다 유한 표본에서 mean·covariance를 함께 추정하는 과정이 병목입니다. 이 진단에는 pass threshold가 없으며 G1/G1r은 계속 실패입니다. 후속 DA2는 세 새 development seed에서 empirical NLL과 geometry-grouped unbiased/shrinkage estimator를 동일한 network와 sampled-validation 기준으로 비교합니다. 방법은 원래 G1r과 같은 768×8에서 선택하고 3,072×8은 데이터 증가 control로만 사용합니다. Pairwise U-statistic covariance는 unbiased sample covariance와 같은 통계량입니다. 이는 estimator 선택용이며 성공 판정이나 3D 실행 권한이 아닙니다. 실제 결과에서 shrinkage 0.50의 평균 개선은 0.23%뿐이고 한 seed에서는 악화돼 새 method로 채택하지 않았습니다. Geometry를 3,072로 늘린 원래 empirical NLL만 최악 2.71%로 안정화됐습니다. Fresh G1s는 같은 estimator와 3,072×8 training budget에서 7개 frozen check를 모두 통과했습니다. 최악 density/end-to-end mean은 2.86%/2.98%, coverage error는 0.84%/1.29%였습니다. 과거 G1/G1r은 failed로 보존하고 이 data-adequacy pass를 novelty로 세지 않습니다. 이후 nonlinear N0는 9개 check 중 8개를 통과했지만 worst-seed nonlinear departure가 실패했습니다. N0a는 기존 seed의 24×12 전체 격자를 읽는 원인 분석일 뿐 성공 판정, N0 재채점, N1/3D 실행 권한이 없습니다. Failed seed의 contiguous/stratified/all-case median은 0.00774/0.01221/0.01828이었지만, context 5–6개는 former reference보다 낮아 모든 context가 강하게 비선형이라고 해석하지 않습니다. N0r는 N0a 결과 전에 fresh seed와 24-context selector를 고정했고, PDE·threshold·worst-seed rule은 N0와 동일하게 유지해 9/9를 통과했습니다. 이후 N1c strong-baseline outer test는 field distribution, paired response와 acquisition regret에서 실패했습니다. N1c-a에서도 joint density는 세 mask 모두 independent heads보다 0/5 seed로 열세였고, stable acquisition과 corrected route regret가 method superiority를 회복하지 못했습니다. 현재 3D는 닫혀 있습니다. 결과 전에 별도 config로 고정한 네-objective density audit에서는 full-joint가 raw conditional objective의 excess를 세 mask에서 20.3–27.2% 줄였습니다. Learned-model-free task audit에서는 missing acquisition이 비자명하고 안정적이지만 sparse-2는 모든 context에서 같은 component가 최적이었습니다. 이는 method novelty나 N1c·3D 상태 변경 근거가 아닙니다. 후속 M0는 missing에서 candidate BC–solution functional joint pushforward만 한 번 검증하도록 사전등록했지만 2/3 seed만 완료되어 aggregate와 과학적 판정이 없습니다. 성공 seed를 선택 집계하거나 sampler를 고쳐 반복하지 않습니다. GLOSSARY · 16 TERMS

용어가 막힐 때
여기로 돌아오세요.

Boundary condition · BC

계산 영역의 입구와 출구에서 유량·속도·압력 등이 어떻게 주어지는지 정하는 조건.

Calibration

0.7로 예측한 집단에서 실제 양성이 약 70%인지처럼, 확률의 크기가 현실 빈도와 맞는 성질.

CFD

유체의 보존 방정식을 mesh 위에서 수치적으로 풀어 속도·압력장을 얻는 계산.

Cross-sectional status

한 시점에 관측된 ruptured/unruptured 상태. 미래 발생 시간을 예측하는 risk와 다름.

Edge

graph에서 두 node의 관계. mesh의 삼각형 이웃 또는 가까운 점을 연결.

Functional

전체 field에서 계산한 TAWSS, OSI, hotspot 면적 같은 요약 함수.

GNN

node가 edge를 따라 이웃의 정보를 모으고 표현을 갱신하는 신경망.

Latent variable

직접 관측하지 않지만 모델 내부에서 변화 원인을 나타내는 숨은 변수. AURORA에서는 BC scenario를 표현.

Mesh

3차원 표면이나 부피를 점, 선, 삼각형, 사면체 등으로 나눈 계산 표현.

Message passing

이웃 node의 특징과 edge 관계로 메시지를 만들고 합쳐 현재 node를 갱신하는 연산.

Neural operator

고정 크기 벡터가 아니라 입력 함수·geometry에서 출력 함수를 학습하는 모델 계열.

OOD

학습 분포 밖의 geometry, BC, 기관 등 처음 보는 조건.

OSI

한 cardiac cycle 동안 WSS 방향이 얼마나 진동하는지 나타내는 지표.

Query point

학습된 operator에 “이 좌표의 값은?”이라고 묻는 공간 위치.

Surrogate

비싼 CFD solver의 입력–출력 관계를 학습해 빠르게 근사하는 모델.

WSS

흐르는 혈액이 혈관 벽을 접선 방향으로 미는 단위 면적당 힘, wall shear stress.
