01 · THE THESIS

좋은 모델보다 먼저,
맞는 문제를 정의한다.

geometry-only 입력에서 혈류는 유일하지 않다. 이 구조적 불확실성을 숨긴 채 GNN의 RMSE만 줄이는 대신, 무엇을 알고 무엇을 모르는지 모델의 출력에 남긴다.

OLD / REJECTED

Module stacking

In-PI-MGN 위에 attention, masking, multigrid를 계속 쌓는다.

  • 배포 때 initial flow와 inlet이 없음
  • 2026 경쟁작과 방법 novelty가 겹침
  • rollout RMSE와 임상 signal 사이가 비어 있음
NEW / ADOPTED

Distributional sufficiency

BC uncertainty를 주변화하고 downstream에 충분한 field를 학습한다.

  • observed / partial / missing BC를 같은 모델로 처리
  • one-shot cycle coefficient로 rollout drift 제거
  • field → functional → decision을 모두 검증

논문이 답할 세 질문

  1. 01 Missing BC를 분포로 다루면 OOD calibration이 좋아지는가?
  2. 02 One-shot cycle이 wall functional을 더 잘 보존하는가?
  3. 03 Surrogate가 real-CFD의 incremental signal을 유지하는가?

05 · PAPER BLUEPRINT

AURORA

Boundary-Condition Marginalized Neural Operators for Task-Aligned Intracranial Aneurysm Hemodynamics

C1

Distribution, not imputation

Missing BC를 함수공간 분포로 모델링하고 observed/missing mode를 같은 operator에서 평가한다.

C2

Cycle, not rollout

One-shot dual-domain temporal coefficients로 전역 flow와 국소 wall shear를 연결한다.

C3

Sufficiency, not RMSE alone

real-CFD의 incremental status signal을 얼마나 보존했는지 risk-retention으로 측정한다.
