01 · THE THESIS

좋은 모델보다 먼저,
맞는 문제를 정의한다.

geometry-only 입력에서 혈류는 유일하지 않다. 이 구조적 불확실성을 숨긴 채 GNN의 RMSE만 줄이는 대신, 무엇을 알고 무엇을 모르는지 모델의 출력에 남긴다.

OLD / REJECTED

Module stacking

In-PI-MGN 위에 attention, masking, multigrid를 계속 쌓는다.

  • 배포 때 initial flow와 inlet이 없음
  • 2026 경쟁작과 방법 novelty가 겹침
  • rollout RMSE와 임상 signal 사이가 비어 있음
NEW / ADOPTED

Coherent condition family

하나의 joint BC model을 조건화해 모든 mask의 field 분포를 만든다.

  • full / partial / missing BC가 tower property를 공유
  • 동일 geometry의 paired BC response를 직접 감독
  • BC-induced와 model-induced uncertainty를 분리

논문이 답할 세 질문

  1. 01 임의의 BC observation mask에서 조건부·주변 분포가 일관되는가?
  2. 02 Paired response supervision이 BC 변화의 Δfield를 개선하는가?
  3. 03 두 uncertainty 축이 condition shift와 geometry OOD를 구분하는가?

03 · MODEL ARCHITECTURE

One joint condition model.
Many coherent views.

관측된 BC component가 달라도 같은 joint density를 conditioning하고, 동일 conditional solution operator로 field distribution을 만든다.

IS IT A GNN? GNN을 포함하지만, 순수 GNN은 아니다.

Local surface는 graph message passing, 장거리 anatomy는 physics-token attention, 임의 좌표의 field는 neural-operator query decoder가 담당한다.
