01 · THE THESIS

확보한 데이터의 구조를
평가 문제로 바꿉니다.

Aneumo는 임상 outcome cohort가 아니라 synthetic steady-CFD release입니다. 그 약점을 숨기지 않고, 동일 형상·정렬 좌표·여러 유량이라는 고유한 강점을 이용합니다. 한 reference solve 이후의 sensitivity sweep를 가속하되, 단순한 Cartesian field 평균 오차가 아니라 유량에 대한 CFD response를 보존하는지를 묻습니다. 이 질문은 P0의 안정성과 P1의 matched failure가 확인될 때만 논문 정체성이 됩니다.

INSUFFICIENT · FIELD ERROR ONLY

Predict each flow and average the voxelwise error

개별 field가 가까운지만 재면 sensitivity curve의 왜곡을 놓칠 수 있다.

  • Anchor 오차가 모든 response에 공통으로 전파됨
  • Gain·direction·tangent가 평균 L2에 가려질 수 있음
  • 먼저 matched-baseline failure를 관측해야 함
CONDITIONAL · RESPONSE FIDELITY

Preserve what the sweep is meant to measure

같은 case의 anchor-relative response를 독립적인 application endpoint로 검증한다.

  • 20/6/6 generation-family split을 유지
  • Strong analytic scaling과 operator/GNN controls
  • 최소 50 untouched family로 one-shot confirmation

논문을 열거나 닫는 세 질문

  1. 01 여덟 유량에서 response endpoint가 node subset·flow interpolation에 안정적인가? P0 미평가.
  2. 02 Field-error-matched strong baselines가 response fidelity에서 실제로 갈리는가? P1 미등록.
  3. 03 최소 factorization이 field accuracy를 해치지 않고 response를 개선하는가? Model 미선택.

02 · EVIDENCE LINEAGE

Novelty is a gap,
not a decoration.

각 계보가 해결한 문제와 남긴 빈칸을 분리한다. 2026년 arXiv preprint는 peer-reviewed evidence로 과장하지 않되 직접 경쟁작으로 포함했다.

CURRENT GAP STATUS

The gap is response selection, not an operator name.

Aneumo는 multi-flow DeepONet을, DeltaPhi는 nearby-state residual을, DINO/DIFNO는 derivative-aware operator를, 최신 aneurysm GNN과 PointNet은 inflow-aware field surrogation을 이미 다룹니다. 따라서 residual, GNN, equivariance 또는 derivative loss 자체는 novelty가 아닙니다. 남은 빈칸은 field-error-matched 모델을 response endpoint로 다시 비교했을 때 유의미한 순위·오차 차이가 실제로 존재하는지, 그리고 그 failure에 직접 연결된 최소 구조가 이를 줄이는지입니다.

03 · CONDITIONAL ARCHITECTURE HYPOTHESIS

Factor the known physics.
Learn only its residual.

아래 구조는 P0와 P1이 모두 통과할 때만 개발하는 가설입니다. 같은 case의 nominal field를 train-fitted power law로 먼저 이동시키고, 0-at-anchor factor를 곱한 국소 residual만 학습합니다. Geometry encoder는 SE(3)- equivariant graph, MeshGraphNet, PointNet 또는 다른 strong control이 될 수 있지만 그 이름은 contribution이 아닙니다. 핵심은 관측된 response failure에 필요한 만큼만 모델을 추가하는 것입니다.

IS THE CURRENT MODEL A GNN? 아직 아니다. 선택된 모델은 0이며, GNN은 조건부 encoder control이다.

P1에서는 analytic scaling, interpolation, conditional MLP, DeepONet, DeltaPhi와 MeshGraphNet/equivariant control을 먼저 비교합니다. GNN이 좋아 보여서 선택하는 것이 아니라, field L2가 같은 모델 사이의 response 차이가 확인될 때에만 local geometry interaction을 위한 최소 encoder 후보가 됩니다.
